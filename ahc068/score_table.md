# AHC068 スコア早見表

## 前提

- 全 150 ケースで **完全整列（$E=0$）** を達成したと仮定。
- 1ケースあたりの得点（$E=0$ のとき）:

$$
S(T) = N^2 + \mathrm{round}\!\left(10^6 \times \log_2 \frac{10^5}{T}\right)
     = 400 + \mathrm{round}\!\left(10^6 \times \log_2 \frac{10^5}{T}\right)
$$

- 合計得点 = $150 \times S(T)$（全ケースで同じ $T$ と仮定した目安。実際は各ケースの $T$ の合計）。
- 逆算式: $T = 10^5 \big/ 2^{(S-400)/10^6}$。
- もし $E>0$ のケースがあると、そのケースは $400 - E$ しか得られない（雲泥の差）。まず $E=0$ が最優先。

|   順位 | 必要な合計得点（目安） | 1ケース得点 | 必要な $T$（目安） |

| 200 位 |                        |             |                    |

> 記入方法: 順位表で目標順位の合計得点 $X$ を読み取り、$S = X/150$、$T = 10^5 / 2^{(S-400)/10^6}$ で必要 $T$ を逆算できます。
